# ADR-0009: 3 つめの行き先「つながり」（② ふたつの日）を足す

- 日付: 2026-11-07
- 状態: 採用
- 関連: ADR-0010（見た目「便箋と押し葉」。この画面もその言葉で描く）、wireframes 0 節・第9節（S5）・第8節 #28、architecture 5.14・7.1

## 経緯

11/7、開発者から「いつといつが繋がって、どうなってるのか とかAIを使ってる感じを」「登録したものと登録したものが紐づかれている様子を見れたら楽しい気する」と言われた。
これまで「そういえば。」の札（`recalls`）は、書いた直後の S1 と、両端の記憶の S3 でしか見られず、結ばれたものを並べて眺める場所が無かった。

3 案（① 糸、② ふたつの日、③ 星座）を 402pt 幅の見本にして並べ、開発者が **② ふたつの日** を選んだ。
つながった二つのひとことを、上に新しい日・下に昔の日の紙片として一組にし、そのあいだを一本の糸と「2年5か月まえの、あのとき」、つながった理由で結んで新しい順に並べる。
昔の紙片では本文のうち思い出した一文（`evidence`）に印を引き、「読んで選んだ」ことを言葉ではなく糸と引用で見せる。画面の上端の小さな「糸の帯」で、いつといつが結ばれたかを一目で見せる。

「AI を使っている感じ」は、画面の言葉にはしない（「AI」「生成」「送信」は出さない。0 節）。結ばれた二つの日と、その理由と、原文の引用が並ぶこと自体で見せる。

## 決めたこと

### 3 つめの行き先（wireframes 0 節の「下部ナビは 2 つだけ」を変える）

- 下部ナビを **きょう / これまで / つながり** の 3 つにする。ハッシュは `#connections`。S3 を開いた元が S5 なら `#memory/<id>?from=connections`（昔の側は `&recall=<recall id>` で 4.2 の形）、S3 の戻るは「‹ つながり」、ナビの現在地は「つながり」
- 絵は、2 枚の紙片を一本の糸で結んだ形（画面の「ふたつの日」と同じ）。既存の 2 つと同じ 20px・線 1.75。選択中は 2 枚の紙片を `fill-card` で白く抜く
- 帯の作りは変えない（`pt-1` + 項目 58px + `max(env(safe-area-inset-bottom), 6px)`。第8節 #23）。3 等分で、402pt で 1 つ約 123px、375pt で約 114px。文字は `whitespace-nowrap` で折り返さない。3 つの画面のどれでも帯の高さが 68px（ブラウザ）で同じことを撮って確かめた
- S5 は S1 / S2 と同じく `KeepAlive` で残し、位置を覚えて戻す

### API の形（`GET /api/connections`。architecture 5.14）

- `{ items, beads }`。`items` は一組 = 一本の糸 = 一枚（見本の `{ nodes, edges }` は、組の一覧を描くには遠回りなのでやめた）。`memory` が書いたひとこと（新しい側）、`related_memory` が思い出した昔のひとこと
- **`not_related`（関係ないかも）は返さない**。原則 1「AI の推測を事実として確定しない」と原則 2「関係なければ提案しない」から、利用者が関係ないと返した結び目を、結ばれたものとして並べ続けない。札そのものは消さず、S3 では今までどおり退いた札として残り、そこで「関係ないかも」を外せばこの画面に戻る
- 組は新しい 50（P0 ではページ送りなし。続きは P2）、帯の粒は起きた日がわかる記憶 500 まで。札の両端を `memories.user_id` で絞る（X-11）。D1 は `db.batch` で 1 往復。マイグレーションは要らない
- 反応は今ある `PATCH /api/recalls/:id` をそのまま使う（新しい API は作らない）

### 見た目は「便箋と押し葉」（ADR-0010）の言葉に置き換える

見本は 11/7 の前の温かい見た目で描かれていたので、選ばれた A の言葉に置き換えた。

| 見本 | 実装 |
|---|---|
| 新しい日の紙片（card、角丸 16） | 便箋 `.card`（角丸 `radius-card` 14px）。本文は罫の上の明朝（`letter-text`）。自分の言葉なので朱罫を引く |
| 昔の日の紙片（同じ card） | 一筆箋 `.note`（`bg-letter`、`border-note-edge`、角丸 `radius-note` 8px、`shadow-note`、左の朱の二重罫）。本文は罫の上の明朝。封蝋は一覧では付けない（組の数だけ並ぶと多すぎる） |
| `evidence` の `<mark>`（ember-soft、角丸 4） | S3 と同じ蛍光ペンの `mark`（`style.css`） |
| 糸（ember の実線と破線） | 同じ ember。確かめる前は **しつけ糸**（破線と中空の結び目）、「そうだった」で **本縫い**（実線と塗った結び目）、「関係ないかも」は **ほどけた糸**（`line-strong` の破線。見本の `line` は地の上で見えにくい）。状態は `data-stitch` |
| 結び目の 2.5px のふち（card） | その紙の色（上は便箋の `card`、下は一筆箋の `letter`、退いたら `paper`）。糸が紙に通っているように見せる |
| 「✓ そうだった」（moss-soft + moss の縁） | A の判（`border-moss-deep` + `bg-moss-soft` + `shadow-stamp` の二重の輪と ✓ の線画。S3 の「✓ そう」と同じ形） |
| 見出し h1（Zen Maru 22px） | 他の画面と同じ 24px の `font-display`。見出しと添え書きの下に S2 と同じ天の二重罫（`rule-double`） |
| シート（`bg-card` の上に `bg-paper` の紙片） | シートの地を机と同じ紙（`bg-paper` + 手ざわり）にし、便箋と一筆箋を一覧と同じ紙として載せる（便箋の地の上に便箋を置くと紙に見えない）。見出し「そういえば。」の右に封蝋を 1 つだけ置き、「関係ないかも」にしたら外す（RecalledByCard と同じ） |
| 「関係ないかも」の昔の紙片 | `.note-quiet`（地の紙に退き、二重罫が `line` に）。文字は薄くしない |

新しい色は足していない（`@theme` のトークンだけ）。糸と帯の状態の CSS は `style.css` の「S5 つながり」の節にまとめた。

### 糸の帯の振る舞い（土台の作業で決めたこと。`web/src/connections/loom.ts` の `layoutLoom`）

- x = 10 + (t − t0) / (t1 − t0) × (幅 − 20)。t は day ならその日、month は 15 日、year は 7 月 1 日。`unknown` は置かない（「いつだったか」を含む組は一覧には出し、帯には置かない）
- **t0 を組の両端の年まで広げる**: 粒は新しい 500 件で切れるので、粒より古い組の端が帯の外に出ないよう、一番古い年は粒と組の両端から取る
- **t1 を先の日付まで伸ばす**: t1 は今年の翌年の 1 月 1 日。起きた日に先の日付（validate は 2100 年まで受け付ける）があれば、端に積まないようその年の翌年まで伸ばす
- 年の縁の境目は 6px あける。ただし 1 年の幅の 1/3 まで（ずっと昔の記憶があっても縁が潰れない）
- **年の文字の間引きと位置の制限**: 文字が 44px より近づくときは、一番新しい年から数えて間引く。文字の中心は帯の端から 16px の内側に収める（「2024」が帯からはみ出さない）
- **今年だけのときは月の文字**: 年の代わりに 1月・4月・7月・10月を、その月の真ん中に出す（同じ位置の制限）
- 弧の高さは 8 + 30√(span / 帯の幅)。短い糸から順に決め、端を 6px 以内で分け合う糸は先に置いた糸より 6px 高くして入れ子にする（最大 54）
- 実装で足したこと: 帯の幅は実際の幅を測って `viewBox` に渡す（`ResizeObserver`）。362 の `viewBox` を縮めて描くと、375pt の端末で年の文字が 13px 弱になるため。測れないときは 362

### 反応とシート

- 一組のどこを押してもシートが開く（「ひらく ›」の `::after` を組いっぱいに）。シートは DateSheet と同じ div の作り（`role="dialog"`、`aria-modal`、`aria-labelledby` は見出しと隔たり）で、`body` の直下に出し（`Teleport`）、開いている間は後ろ（画面と下部ナビを包む `.safe-area`）に `inert` を付ける。開いたら見出しにフォーカス、閉じたら押した組へ返す。閉じ方は「とじる」・地を押す・Esc
- 「そうだった」「関係ないかも」は S3 の札と同じ。同じボタンをもう一度押すと `none` に戻す。失敗したら印を戻し、ボタンの下に「記録できませんでした」
- 「関係ないかも」にした組は、シートを閉じたときに薄れて上へ抜け（280ms）、一覧と帯から外れる。フォーカスは次の組へ、無ければ h1 へ。最後の 1 組なら空の画面になる
- 実装で足したこと: 閉じて外した後に記録が失敗したら、組を元の印で一覧に戻す。画面を離れたとき（シートの「ひらく ›」で S3 へ、戻るボタン）はシートを動かさずに閉じ、`inert` を外す。S3 で消した記憶の組は取り直しを待たずに外す。取り直しは記録中の組の印を古い値に戻さない

### 動き

- 最初に読み込んだときだけ、組が 90ms ずつずれて 600ms で現れ（5 組目まで）、本縫いの糸は 900ms、帯の弧は 1100ms で描かれる。S3 から戻ったときは裏で取り直して入れ替えるだけで動かさない（KeepAlive で外れた要素を戻すと CSS の動きが最初からやり直されるので、入ってくる動きの class は 2.4 秒で外し、離れるときにも外す）
- シートは地を 200ms で暗くし、340ms で下から上がる。糸は 220ms 遅れて 760ms で描き、結び目は 360ms でとまる。「そうだった」で 640ms かけて本縫いに描き直す
- `prefers-reduced-motion: reduce` では動きも遷移もすべて止めて、状態だけを切り替える（画面の側も待たずに閉じる・外す）

## 時間が無いときに削る順

1. **帯**（`ConnectionsScreen.vue` の `<ThreadLoom>` の 1 行を外す。下の一覧だけで成り立つ。`loom.ts` とテストは残してよい）
2. **入ってくる動き**（`ConnectionsScreen.vue` の `load` で `entering` を立てる 4 行を外す。シートの動きは残す）
3. **シートの反応**（`PairSheet.vue` の反応ボタンと `react` を外す。反応は紙片の「ひらく ›」から S3 で返す（4.2 の形で開くので、反応ボタンが本文のすぐ下に出る））

## まだのこと

- 帯は押せない（押して組へ飛ぶのは、余裕があれば）。50 組を超えた分の「もっと前を見る」は P2
- Android の戻るボタンはハッシュを戻すだけなので、シートを開いたまま押すとシートだけでなく画面ごと前に戻る（DateSheet と同じ問題。シートは閉じて `inert` も外れる）
- 実機で見ること（ヘッドレスの Chrome でしか見ていない）: WKWebView の `inert` と `Teleport` 先の固定配置・セーフエリア、`line-clamp` の中の `mark` の `box-decoration-break`、VoiceOver で `aria-labelledby` の 2 つ（見出しと隔たり）と `role="list"` の読み上げ、SVG の `stroke-dashoffset` の動きの重さ、極端に長い理由での結びの高さ（一覧は 3 行で切る。シートは全文でシートごとスクロールする）
- 一組の高さは、明朝の行送り（31px）で見本の 360〜420px より少し高い（402pt で約 465px）。最初の画面に見えるのは帯と 1 組と少し（見本は 1.5 組）
- 理由の文は Claude の出力しだい（見本の文は実際の札と足しから取った）
