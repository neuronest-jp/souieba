# ADR-0001: 仕様書 v0.2 を依頼文から再構成したドラフトで代替する

- 日付: 2026-11-03
- 状態: 採用（原本は届かなかったので、docs/spec.md を正とする。2026-11-07）

## 背景

依頼文は docs/spec.md（仕様書 v0.2）を基本要件として扱うよう指示しているが、
作業開始時点でリポジトリのどのブランチにも docs/spec.md は存在しなかった。
開発者からは「この端末で対応して」との指示があり、原本の到着を待たずに進める必要があった。

## 決定

依頼文に含まれる要件（スタック、製品原則、第14節の作成順、11/4 スコープ、デモ4シナリオ、
.claude フック、UI 方針）を、依頼文が参照する章番号（第2節・第4節・第13節・第14節）と
矛盾しない章立てで docs/spec.md に再構成し、以降のドキュメントと実装はこれを基本要件とする。

## 影響

- 原本との差分が出る可能性がある。原本到着後、docs/spec.md を置き換え、差分を docs/requirements.md 以降に反映する
- 本ドラフトで Claude Code が独自に決めた点: 想起の最大件数 3、過去記憶の送信上限 200 件、
  日付精度の4段階、ai_runs の記録、画面 S0〜S4 の構成
