- 「ログアウト」「別のアドレスで」は作らない（トークンは 90 日で切れる。設定画面は無い）
- ネイティブではキーボードが出たときカードが隠れないよう、`main` を `flex-1` + `justify-center` にし、入力欄を見える位置まで送るのは WebView に任せる（`ios.contentInset` は `"never"`。セーフエリアは CSS の `env()` だけで取る。第8節 #23）
- 起動直後の判定中（トークンの読み込みと `GET /api/me`）は何も主張しない空の画面（`…` を `text-ink-faint` で中央に。`role="status"` に「読み込んでいます」）。スプラッシュは判定が終わってから隠す
- トークンはあるのに `GET /api/me` が 401 以外で失敗したとき（ネットワーク断）は S0 ではなく「そういえば。」+「いま、うまくつながりません。」+ 副ボタン「もう一度」の画面（`App.vue` の `trouble`）。ログインし直させない

### 2.3 保存直後（候補が並ぶ）

保存すると入力欄は閉じ、残したひとことがカードになる。候補は `GET /facts` の `pending` が false になった時点で本文の下に並ぶ（F4、architecture 5.9）。それまでは何も表示しない。

残した瞬間（ADR-0011 の 8.4。動きを減らす設定ではどれも止め、待たずに入れ替える）:

1. 「保存する」を押すと、書いた便箋が封をされるように沈む（`translateY(3px) scale(.985)`、160ms）。返事が来るまでそのまま、ただし最短 280ms
2. 返事が来たら `saved` の触覚と一緒に、保存後のカードが沈んだ形から浮かんで収まる（280ms）。フォーカスは「残しました」へ
3. 「残しました」の横に手書きの ✓ が 2 画で描かれ（180ms から 150ms、330ms から 230ms）、560ms から「N こめのひとこと」が 280ms で現れる

- 札の上に「関連する記憶」などの見出しは置かない。「そういえば。」自体が見出し
- 札の中に写真は置かない（S3 で見る）。札は一筆箋（`.note`: `bg-letter` + `border-note-edge`、`rounded-note`、`shadow-note`）、内側は左 34px・右 20px・上 20px

- S3 で「関係ないかも」と返した札は、S1 でも退いた札（`.note-quiet`: 地の色の紙、二重罫は `line`、封蝋と押し葉を外す）で出す。見出し「そういえば。」と「ひらく ›」は同じ位置に残す（札は消えない。F6-2。見直し n=6）。退いた札は届いたときの触覚を鳴らさない

## 4. S3 記憶の詳細

役割: 本文、写真、確定済みの事実、関連する「そういえば。」の履歴、削除（第6節）。ハッシュ `#memory/<id>`。`GET /api/memories/:id`（architecture 5.5）の `memory`, `facts.items`, `recalls.items`, `recalled_by.items` を描く。`recalled_by` には `pending` が無い（他の記憶の想起が進行中かどうかはこの画面に関係しない）。開いた記憶の `facts.pending` か `recalls.pending` が true の間（保存した直後に「このひとことをひらく ›」で来たときなど）は、S1 と同じく 2 秒間隔・30 秒で打ち切りで取り直し、届いた候補と札を足す。文言は出さず、書き換えるのは `facts` と `recalls` だけ（画面で決めた候補の印と `recalled_by` の反応はそのまま）。

記憶が無いとき（404。戻るで消した記憶を開いた場合など）と取得に失敗したときは、見出しの位置に、この画面の `h1` として（字体・太さ・行間は本文のまま）`text-ink-soft` 17px で「この記憶は見つかりませんでした」と、その上に戻る（開いた元の画面の名前。‹ きょう / ‹ これまで / ‹ つながり）だけを出す。本文・写真・「消す」は描かない。

出入りの動き（ADR-0011 の 7 節。動きを減らす設定では止める）: 開くと S3 の紙が右から 280ms（`ease-out-soft`）で重なって入り、前の画面は 30% 左へ下がって薄い墨（`ink` の 0.12）が重なる（push）。戻るボタン・下部ナビの開いた元の項目で戻るとその逆（pop）。S3 の札から相手の S3 へ移るときも push（記憶ごとに画面を作り直す）。動いている間の S3 は左右の余白まで机の紙を敷き、左の縁に影を落とす。

左端からなぞって戻る（`useEdgeSwipe`。「消しますか」のシートが出ている間は拾わない）: 画面の左端 24px から右へなぞると、S3 の紙が指に付いて右へ動き、下に机の地が見える（前の画面はここでは描けない）。10px 動いたところで向きを決め、縦が先ならスクロールに任せる。離したとき、幅の 50% より右か、右へ 0.3px/ms 以上で 24px 以上払っていたら戻り（`select` の触覚。S3 は指の位置から右へ出ていき、前の画面は少し左からふわっと出る）、左へ速く払ったかそれ以外は 280ms で元の位置へ。動きを減らす設定では紙を動かさず、右へ 32px なぞった時点で戻る。

## 9. S5 つながり（11/7 に足した 3 つめの行き先。ADR-0009）

役割: 書いたひとことと、そのとき浮かんだひとこと（「そういえば。」の札の両端）を一組にして札の新しい順に並べ、いつといつが結ばれたかを見せる。組の中の上下は起きた日の順（上 = 後の日、下 = 前の日）で、書いた順ではない（昔のことを今日書くと、思い出した方が後の日になる。11/7 実機で、2019 年の引っ越しを書いて 2026 年 7 月の冷蔵庫を思い出した組が「7年3か月あとの」と逆に見えた）。どちらかが「いつだったか」か、同じ日・同じころなら、書いた方を上に置く。思い出した一文の印と、S3 を札の形（`?recall=`）で開くリンクは、上下ではなく思い出された側に付ける（11/7 開発者「登録したものと登録したものが紐づかれている様子を見れたら楽しい」。第8節 #28）。
ハッシュ `#connections`、下部ナビの 3 つめ「つながり」から入る。`GET /api/connections`（architecture 5.14）の `items`（組。新しい 50 まで）と `beads`（帯の粒）を描く。`not_related` の組は API が返さない（原則 1・2）。
反応は S3 の札と同じ `PATCH /api/recalls/:id`。見た目は「便箋と押し葉」（ADR-0010）: 上（後の日）は便箋、下（前の日）は一筆箋、そのあいだを糸で結ぶ（紙は位置で決まり、書いた側か思い出された側かでは決まらない）。
11/7 のブラッシュアップ（ADR-0011、ADR-0009 の追記）で、見直しの指摘の直し（一覧と記録が重なったときの約束、記録の失敗の知らせ、引用の印、シートの手ざわり）と、動き・帯を押す・新しく結ばれた糸の出方を足した。

### 9.5 糸（結びの左）と色だけに頼らないこと

| 状態 | 糸 | 結び目 | 文字 |
|---|---|---|---|
| まだ確かめていない（`none`） | しつけ糸: `ember` 2px の破線 | 中空（紙の色の面に `ember` 2px の縁） | なし |
| そうだった（`helpful`） | 本縫い: `ember` 2px の実線 | `ember` で塗る | 一覧の足に判「✓ そうだった」、シートでは `aria-pressed` |
| 関係ないかも（`not_related`、シートの中だけ） | ほどけた糸: `line-strong` の破線 | 中空、縁は `line-strong` | `aria-pressed`、下の紙片が地の紙に退き封蝋が外れる |

糸は viewBox 0 0 40 100 に `preserveAspectRatio="none"` で描き、結びの高さを測らずに上下の紙の縁から縁まで届かせる。揺れの向きは組ごとに左右を入れ替える。
結び目は 11px の輪を紙片の縁に半分かけ、その紙の色（上は `card`、下は `letter`、退いたら `paper`）の 2.5px のふちで、糸が紙に通っているように見せる。
確定の見た目（実線・塗り）にするのは、利用者が「そうだった」と確かめた糸だけ（AI の推測を事実として見せない。原則 1）。

### 9.7 動き

11/7 のブラッシュアップで値を変えた（トークンは quick 160 / base 280 / slow 460ms。`styles/connections.css`）。動かすのは `transform` と `opacity` だけで、帯の弧も糸も `stroke-dashoffset` で描かない。

- 最初の表示: 組が 70ms ずつずれて（6 組目まで）、下から 14px・460ms・`ease-out-soft` で現れる。結び目は 280ms・`ease-spring` で留まり（上は 140ms、下は 560ms 遅れ）、本縫いは 8 針を上から 45ms ずつ（各 160ms）で現し、しつけ糸は 460ms でにじみ出る。
  帯の弧は古い端から 120ms + 70ms ずつ（11 本目まで）、縁から 460ms・`ease-spring` で立ち上がり（`scaleY` 0.12 → 1）、両端の結び目はその 200ms あとに留まる。すべて終わるまで 1.9 秒（そのあと class を外す。`ConnectionsScreen.vue` の `WEAVE_MS`）
- S3 から戻ったとき・下部ナビで戻ったとき: 裏で取り直して入れ替え、前に見たときより後に結ばれた組（と帯のその弧）だけが同じ動きで現れる。ほかは動かさない（位置もそのまま）。自分が書くと糸が増えることが目で見える（ADR-0011 の 8.7）
- シート: 紙と地は 9.4（`useSheetDrag`）。開いたら 220〜240ms 遅れて糸を一針ずつ渡す（しつけ糸は 220ms から 460ms でにじみ出る、本縫いは 240ms から 45ms ずつ。結び目は 180ms から留まる）
- 「そうだった」: しつけ糸の上を本縫いが 55ms ずつ 8 針で上から縫い直す。しつけ糸は 560ms で消え、下の結び目は 440ms で留まって塗られる。ボタンは判のように 280ms・`ease-spring` で弾む（0.88 から）。押している間は `.choice:active` で沈む
- 「関係ないかも」のまま閉じた組: 280ms で薄れて 12px 上へ抜け、下の組は 460ms・`ease-out-soft` で元の位置から詰まる（FLIP。`transform` だけ。画面の外の組は動かさない）
- 帯を押したとき: 組と弧が 1.4 秒ほのかに光る（9.2）
- 組は押すと `.press` で沈む（0.97）
- 触覚（ADR-0011 の 3 節）: 「そうだった」で `stamp`、「関係ないかも」と取り消しで `tap`（どれも押した直後に 1 回）、記録の失敗で `failed`、帯の弧を押したら `select`。組を押してシートを開くときは鳴らさない
- `prefers-reduced-motion: reduce` では動きも遷移もすべて止め、状態だけを切り替える（帯から飛ぶのはスクロールせずに飛び、光は動かない淡い光を 1.4 秒）

### 9.8 読み上げとフォーカス

- `h1` は「つながり」。画面を移ったら useScreen が `h1` へフォーカスを置く
- 帯は `<figure aria-hidden="true">`。同じことはすべて一覧に文字で書いてある
- 一覧は `<ol role="list" aria-label="つながりの一覧">`（`list-style: none` で Safari / VoiceOver がリストと読まなくなるので `role` を明示）。各組は `<article aria-labelledby>`（上の紙片の日付）。読む順は見た目と同じで「11月7日（土）のひとこと → 本文 → 2年5か月まえの、あのとき → 理由 → 2024年6月のひとこと → 本文（引用は「」で読む。`mark` の前後の `sr-only` の「」）→ ✓ そうだった → 記録できませんでした（どちらか一方だけのこともある）→ ひらく」。糸と結び目は `aria-hidden`
- 画面に常に置いた読み上げ用の知らせ（`sr-only`、`role="status"`、`aria-live="polite"`）が、シートを閉じたあとの記録の失敗を「記録できませんでした」と読む（初めから置いて文字だけ入れ替える）。シートの中の `role="status"` も常に置く
- 「ひらく ›」の名前は「ひらく、11月7日（土）と2024年6月のつながり」（見えている「ひらく」を先頭に）。`aria-haspopup="dialog"`、`aria-controls`
- シートは `role="dialog"`、`aria-modal="true"`、`aria-labelledby` は見出しと隔たり。`body` の直下に出し、開いている間は後ろ（画面と下部ナビ）に `inert`。開いたら見出し（`tabindex="-1"`）にフォーカス、閉じたら押した組の「ひらく」へ返す。「関係ないかも」で組が外れたときは次の組へ、無ければ `h1` へ。シートを開いたまま画面を離れたら（紙片の「ひらく ›」、戻るボタン）、シートを閉じて `inert` を外す
- Android の戻るボタンはハッシュを戻すだけなので、シートだけを閉じず画面ごと前に戻る（DateSheet と同じ。ADR-0009 のまだのこと。Android の調整はしない。ADR-0011）
