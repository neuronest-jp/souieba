# ADR-0008: iOS の標準の見た目を試して戻した。iOS の作法は守り、見た目は自前にする

- 日付: 2026-11-07
- 状態: 採用
- 関連: ADR-0004（デザイン基盤。こちらを引き続き正とする）、wireframes 第8節 #22〜#25

## 経緯

1. 開発者が実機で「デザインを可能な限り iOS 27 の標準のものに近づけて」と判断した。iOS 27 は iOS 26 の Liquid Glass を引き継いでいるため、
   システムの色（`#F2F2F7` の地、白い欄、黒い文字）と字体（ヒラギノ / SF）、34pt の大見出し、浮かぶガラスのタブバー、インセットグループの一覧、
   カプセルのボタン、浮いたシートとセグメントに寄せた（5fe681d）
2. 実機で見た開発者の判断は「あまりにも iOS のデザインをパクりましたで気持ち悪い」「Xcode じゃないからか」。取り消した（b8aabbd）

## 何が起きていたか

このアプリは Capacitor の WebView に HTML と CSS で描いた画面を出している。iOS の本物の部品（光が屈折する Liquid Glass、SF Symbols、バネの動き、
日付を選ぶネイティブのシート）は CSS では作れない。そっくりに寄せるほど「ほぼ同じだが何か違う」偽物に見える。
本物の iOS の見た目は SwiftUI（Xcode）で書けば出るが、スタックは Capacitor + Vue（Android と画面を共有）に決まっていて変えない（CLAUDE.md）。

## 決めたこと

- **見た目は自前（ADR-0004 の温かい色と丸い字体、選んだ C 案の下部ナビ）にする。iOS の部品の見た目は真似ない**
- **iOS の作法は守る**: 大きさ（本文 17px、押せる所 44px 以上）、セーフエリア（ADR とは別に cf0b53d で `contentInset: "never"` にした）、
  下から出るシートと掴み手、行全体が押せる一覧、端末の字体への逃げ道
- 試したときの改善のうち、真似ではないものは残す:
  - S2 の写真の無い行に空の枠を置かない（左に 56px の空きがあった）
  - 字体の CSS（Google Fonts）は描画を止めない読み方にする（`media="print"` で読み、届いたら `all`）。通信が遅いと画面が白いまま待っていた。
    届くまでは iOS ではヒラギノ丸ゴ（見出し）とヒラギノ角ゴ（本文）で出す。どちらも iOS に入っている字体なので画像や配布を伴わない
  - 「いつ？」のシートの日付欄: iOS の WebKit が `input[type=date|month]` に固有の幅を持たせ、`w-full` でもシートの右にはみ出していた。
    `appearance: none; min-width: 0; display: block` にした（style.css）。シートの上に掴み手を足した
- **スプラッシュ画面**（開発者の希望）: 地の色 `#FAF5EC` に、Zen Maru Gothic の太字で「そういえば。」、句点だけ ember。
  iOS は起動画面（`LaunchScreen.storyboard`）とスプラッシュ（`Splash.imageset`）が同じ画像なので、タップから画面が出るまで一続きに見える。
  Android は `res/drawable*/splash.png` を解像度ごとに同じ見た目で作り、`androidScaleType: "CENTER_CROP"` で縦横比を崩さない。
  起動から少なくとも 0.9 秒は見せてから 0.3 秒で消す（`native.ts` の `hideSplash`）。3 秒は画面が動かなかったときの保険
  - 文字の画像は、ブラウザで Zen Maru Gothic（SIL Open Font License。画像にして配ってよい）を描いて撮り、形だけを取り出して地・文字・句点を正確な色で描き直した
    （撮ると画面の色の扱いで地が `#FBF2E9` にずれ、アプリの地との境目が見えるため）

## まだのこと

- アプリのアイコンが Capacitor の既定のまま（青い X）。ホーム画面と Android 12 以降の起動画面に出る。素材は開発者が権利を持つものだけ（setup-capacitor 4 節）なので、案を作るかどうかは開発者の判断
