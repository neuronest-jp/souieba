# ADR-0010: 見た目を「便箋と押し葉」にする（紙の役割で言葉の出どころを見せる）

- 日付: 2026-11-07
- 状態: 採用
- 関連: ADR-0004（デザイン基盤。下の「変えたこと」の分だけ上書きする。ほかは引き続き正）、ADR-0008（地の色とスプラッシュ）、wireframes 第8節 #27

## 経緯

11/7、温かい自前の見た目を深める案を 3 方向で 402pt 幅の見本（S1 保存後、S2、S3）にして並べ、開発者が **A「便箋と押し葉」** を選んだ
（同じ日に、新しい「つながり」画面は「② ふたつの日」を選んだ。そちらは別の ADR）。

A の芯は、製品原則を文字を読まなくても形で見せること。

- 自分の言葉は、朱罫の便箋に明朝で書かれている（原文）
- 昔の記憶から届く「そういえば。」は、封蝋の付いた一筆箋
- 候補は、ミシン目から下の控えの紙に鉛筆書き（点線の下線と点線の区切り）
- 確かめたものには判（二重の輪と ✓）。「関係ないかも」と返した札は封蝋が外れ、地の紙に退く

模様は封蝋・押し葉・栞の 3 つだけにし、どれも意味のある場所にしか出さない。回転も散らした飾りも入れない。

### 地の色を変えなかった理由

見本は地を `#F5EDDF` に深くして便箋との差を出していた。しかしスプラッシュ（iOS の `LaunchScreen` と `Splash.imageset`、Android の `splash.png`、
`SplashOverlay.vue`）とステータスバーは、ADR-0008 で `#FAF5EC` に正確に描き直してあり、地を変えると起動から画面に移るところに境目が出る。
描き直すより、見本の risks 1 の逃げ道どおり **地は `#FAF5EC` のまま、便箋を `#FFFEFA` に上げて差を付ける** ことにした。
一筆箋と控えも、地と便箋の間に収まるよう選び直した（見本の `#FDF6E9` / `#F8F1E4` は地を深くした前提の値）。
地と便箋の差は見本より小さい（OKLab の明るさで 0.025。見本は 0.043）が、便箋は縁と影、一筆箋は縁・影・朱の二重罫・封蝋で、色の差に頼らず別の紙に見える。

### 字体

- 自分の言葉と原文の引用（S1 の入力欄と記憶カード、札の引用、S2 の 1 行目、S3 の本文、候補の根拠）は **Zen Old Mincho**（500 / 600。SIL Open Font License）。
  `font-letter` = `"Zen Old Mincho", "Hiragino Mincho ProN", serif`
- 読み込みは `web/index.html` の既存の Google Fonts の link に足した（`media="print"` で読み、届いたら `all`。描画を止めない）。unicode-range で分かれているので、使う字の分だけ届く
- 届くまでは iOS ではヒラギノ明朝で出る。Android には日本語の明朝が無いので角ゴシックで出る（下の行送りの決め方で、どの字体でも罫と行はずれない）
- 見出しとボタンは Zen Maru Gothic、補足と値は Noto Sans JP のまま（ADR-0004）。ADR-0004 の「本文は Noto Sans JP」は、自分の言葉と引用に限って明朝に上書きする

### 行送りと朱罫

- 罫を引くのは自分の言葉と「」の引用だけ（入力欄、S1 の記憶カード、札の引用、S3 の本文）。S2 の 1 行目と候補の根拠は明朝で罫なし
- 罫は文字の背景の `linear-gradient` で、各行の下 1px だけを `rule` の色にする（`@utility letter-text`）
- **行送りと罫の間隔を同じ em から出す**: `--leading-letter: calc(31em / 17)`。17px のとき 31px ちょうど（見本の 31px と同じ。17 × 1.8 = 30.6 を罫の間隔に丸めた値）。
  `line-height` と `background-size` の両方がこの値を使うので、文字の大きさが変わっても（Android の WebView の文字の大きさの設定、将来の文字サイズの変更）罫と行はずれない。
  罫の位置の上げ幅（`calc(-2em / 17)`）と下の余白（`calc(2em / 17)`）も em にした
  - 31px の固定にしなかったのは、文字だけが拡大されると行送りが追いつかず、罫が文字に重なるため
  - `1lh` にしなかったのは、iOS 16.4 より前の WebKit で効かないため（em なら同じことがどこでも効く）
  - ブラウザで `.letter-text` の文字を 22px にして撮り、7 行の本文で罫と行がそろうことを確かめた
- 入力欄（`textarea`）は 4 行分の罫を最初から引き（`min-height` も同じ em から。はじめは 5 行だったが、書く前の画面が iPhone でスクロールになったため 11/7 に 4 行にした）、罫は文字と一緒に流れる（`background-attachment: local`）

### 形

- 角丸 `radius-card` を 20px → **14px**（紙の角に寄せる。ADR-0004 の「16〜24px」から外れる）。一筆箋は `radius-note` 8px
- 影: `shadow-card`（紙の薄い厚みと落ち影）、`shadow-note`（赤茶の落ち影）、`shadow-press`（紙のボタンの厚み）、`shadow-print`（写真の焼き付け）、
  `shadow-stamp`（判の内側の二重の輪）、`shadow-highlight`（選択中の地のつや）、`drop-shadow-wax`（封蝋と栞）
- 一筆箋の「左縁の ember 3px」は、内側の朱の二重罫（2px と 1px）に描き直した（wireframes 2.4・4.1）
- ミシン目: 1.5px の点線の上罫と、カードの左右の縁の半円の切り欠き（`.perf`）。控え（`.slip`）はその下
- 天の二重罫（1px の線 2 本）: S2 の見出しの下、S3 の「おぼえていること」の下、下部ナビの上の縁（ナビは `line` の色）
- S2 の写真は白いふちの焼き付け（3px のふち、角丸 4px）。S3 の本文は便箋に入れ、引用の範囲は蛍光ペンを下 7 割に引いた印（`mark`）
- 下部ナビは C 案（ADR-0008）の作りのまま、帯をすりガラスから地と同じ紙にし、上の縁を二重罫に、項目を 58px にした。
  帯の高さは `pt-1` + 58px + `max(env(safe-area-inset-bottom), 6px)` だけで決まる（起動直後と切り替え後で変わらない。第8節 #23）。選択中は絵の鉛筆の軸と押し葉を白く抜く
- ステータスバーの下の地（`App.vue`）も、ナビと同じく不透明な紙にした（片方だけすりガラスにしない）

### 色だけに頼らない（wireframes 6 節）

- 候補: 「」か明朝の根拠、値の点線の下線、点線の区切り、「そう」「ちがう」のボタン（S1 では見出しの前に鉛筆）
- 確定: ボタンが消え、二重の輪の判に ✓ の線画（読み上げは「✓ そう」のまま）。区切りは実線
- 却下: いまどおり打ち消し線と、読み上げ用の見えない「、ちがう」
- 「関係ないかも」の札: 封蝋が外れ、地の色の紙になり、二重罫が `line` に変わる（`aria-pressed` も付く）。「そうだった」は判の形
- 原文かどうか: 字体（明朝）と罫と「」の 3 つ
- 封蝋・押し葉・栞・鉛筆・チェックの絵はすべて `aria-hidden`

### 押せる所と動き

- そう / ちがうは見た目 36px、`::after` で上下に広げて 44px。そうだった / 関係ないかもは見た目 40px で 48px。札は全体が「ひらく」の領域。テキストボタンは 44px 以上
- 札は 600ms のフェードと 8px の上昇（`.appear`）、そこから 380ms 遅れて封蝋が 420ms で押される（scale 1.25 → 1）。`prefers-reduced-motion` では両方止める

### 手ざわり

- 紙の粒（`feTurbulence` を 220px で繰り返す SVG）と和紙の繊維（二次曲線 18 本を 360px で繰り返す SVG）。画像素材は使わず、その場で書いた SVG の data URI
- 地とナビとステータスバーの下には繊維と粒、便箋・一筆箋・控え・シートには半分の濃さの粒。`background-attachment: fixed` は使わない
- data URI の `%23` の色は `style.css` にだけ置く（`pnpm check:words` は `.vue` の色リテラルを検査する。`style.css` は対象外）

## 時間が無いときに削る順

1. **栞**（S3 の便箋の天。`Ribbon.vue` と `MemoryDetailScreen.vue` の 1 行を外す。無くても本文の印で成り立つ）
2. **封蝋の押される動き**（`style.css` の `.appear .seal` を外す。封蝋そのものは残す）
3. **手ざわり**（`--tex-*` と `tex-desk` / `tex-sheet` を外す。色と形はそのまま）

## 実機で見ること（ヘッドレスの Chrome でしか見ていない）

- WKWebView（Safari の WebKit）での `line-clamp-3` と、「」をぶら下げる `text-indent: -1em` の組み合わせ（札の引用）
- `mark` の `box-decoration-break: clone`（2 行にまたがる印の角）
- `textarea` の `field-sizing: content`（使えない WebKit では `rows` と `min-height` の 4 行分で止まる。iOS 27 の WebKit では効き、10 行まで伸びることを Simulator で確かめた）
- `feTurbulence` 入りの背景の描画の重さ（古い Android の WebView）と、Android で明朝が角ゴシックで出たときの見え方
- 4 行を超える本文で罫と行がずれないか

## 追記: ブラッシュアップ（11/7、ADR-0011）

- **地の色**: 「地の色を変えなかった理由」の #FAF5EC は朝と昼の地として残し、夕方（17〜20 時）は `paper-evening` #FFF4E7、夜（21〜4 時）は `paper-night` #FEF5E0 に `--color-paper` を差し替える（`styles/season.css`）。
  相対輝度を #FAF5EC 以上に保ち、色相だけを動かしたので、上のコントラストの表の `paper` の列は下がらない。スプラッシュ・起動画面・`backgroundColor` は #FAF5EC のまま。便箋・一筆箋・控えは変えない（ADR-0011 の 9 節。`applyTimeOfDay` を `main.ts` から呼ぶまでは効かない）
- **押し葉と封蝋**: 形を季節で替える（春 桜の小枝 / 夏 青もみじ / 秋 紅葉 / 冬 南天。封蝋は浮き出しの線画だけ）。色は `styles/season.css` の季節のトークン。置き場所と大きさ、「模様は封蝋・押し葉・栞の 3 つだけ」「回転も散らした飾りも入れない」は変えない
- **動き**: 「押せる所と動き」の札の値（600ms のフェードと 8px、380ms 遅れて 420ms、scale 1.25 → 1）は、札（`.note.appear`）では 18px・460ms のすべり込みと、360ms 遅れて 400ms（scale 1.4 → 0.94 → 1）に変えた。札以外の `.appear` は 600ms・8px のまま。
  動きのトークン（quick 160 / base 280 / slow 460ms、`ease-spring` / `ease-out-soft`）と押したときの沈み（`.press`）は ADR-0011 の 6 節
- **打ち消し線**: 却下した候補の打ち消し線を 1px から 1.5px にした（細いと漢字の上でほとんど見えない）
- **時間が無いときに削る順**の 2「封蝋の押される動き」は、いまは `style.css` の `.appear .seal`（`seal-press`）を外す（`arrive` の触覚は `motion.ts` の `arriveSoon` が鳴らすので、動きを外しても残る）
