# ADR-0004: デザイン基盤（カラー・フォント・動き）

- 日付: 2026-11-03
- 状態: 採用（仕様書原本に指定があれば上書き）

## 背景

UI 方針は「テクノロジーを意識させない温かい記憶のアプリ」。AI チャット画面を中心にしない。
仕様書ドラフトにカラー・フォントの指定がないため、ここで決める。

## 決定

### カラー（Tailwind v4 の `@theme` トークン）

| トークン | 値 | 用途 |
|---|---|---|
| `--color-paper` | `#FAF5EC` | 画面の地。和紙のような温かい生成り |
| `--color-card` | `#FFFDF8` | 札・カード |
| `--color-ink` | `#3A3230` | 本文の文字。真っ黒にしない |
| `--color-ink-soft` | `#6F655D` | 補足の文字 |
| `--color-ink-faint` | `#A69C92` | 日付、プレースホルダ |
| `--color-line` | `#E6DCCD` | 罫線、枠 |
| `--color-ember` | `#C9684A` | 主アクション、「そういえば。」の印。柿色寄りの朱 |
| `--color-ember-soft` | `#F3DED3` | 主アクションの地、選択状態 |
| `--color-moss` | `#7E9478` | 確定（そう）の印 |
| `--color-moss-soft` | `#E3EADF` | 確定の地 |

ダークモードは提出スコープ外（ライトのみ）。

### フォント

- 見出し・アプリ名・「そういえば。」の札: **Zen Maru Gothic**（丸ゴシック。角を取り、手紙のような柔らかさ）
- 本文: **Noto Sans JP**
- 読み込み: Google Fonts（SIL Open Font License）。読み込み前は `system-ui, "Hiragino Sans", "Yu Gothic", sans-serif` で表示（FOUT を許容）
- サイズ: 本文 17px / 行間 1.8。見出し 22〜28px。日付など補足 14px

### 形と動き

- 角丸は大きめ（16〜24px）。影は薄く、縁は `--color-line`
- 「そういえば。」の札は 600ms のフェードとわずかな上方向スライドで現れる。音や通知は使わない
- ボタンの文言は「保存する」「そう」「ちがう」「そうだった」「関係ないかも」のように短い日本語。「送信」「AI」「生成」という語は画面に出さない

## 影響

- `web/src/style.css` の `@theme` に上記を定義し、コンポーネントは色を直書きしない
- 依存は `tailwindcss` と `@tailwindcss/vite` のみ。UI ライブラリは入れない
