# ADR-0009: 3 つめの行き先「つながり」（② ふたつの日）を足す

- 日付: 2026-11-07
- 状態: 採用
- 関連: ADR-0010（見た目「便箋と押し葉」。この画面もその言葉で描く）、ADR-0011（ブラッシュアップ。末尾の 2 つめの追記）、wireframes 0 節・第9節（S5）・第8節 #28・#29、architecture 5.14・7.1

## 経緯

11/7、開発者から「いつといつが繋がって、どうなってるのか とかAIを使ってる感じを」「登録したものと登録したものが紐づかれている様子を見れたら楽しい気する」と言われた。
これまで「そういえば。」の札（`recalls`）は、書いた直後の S1 と、両端の記憶の S3 でしか見られず、結ばれたものを並べて眺める場所が無かった。

3 案（① 糸、② ふたつの日、③ 星座）を 402pt 幅の見本にして並べ、開発者が **② ふたつの日** を選んだ。
つながった二つのひとことを、上に新しい日・下に昔の日の紙片として一組にし、そのあいだを一本の糸と「2年5か月まえの、あのとき」、つながった理由で結んで新しい順に並べる。
思い出された側の紙片では本文のうち思い出した一文（`evidence`）に印を引き、「読んで選んだ」ことを言葉ではなく糸と引用で見せる。画面の上端の小さな「糸の帯」で、いつといつが結ばれたかを一目で見せる。

「AI を使っている感じ」は、画面の言葉にはしない（「AI」「生成」「送信」は出さない。0 節）。結ばれた二つの日と、その理由と、原文の引用が並ぶこと自体で見せる。

## 決めたこと

### 3 つめの行き先（wireframes 0 節の「下部ナビは 2 つだけ」を変える）

- 下部ナビを **きょう / これまで / つながり** の 3 つにする。ハッシュは `#connections`。S3 を開いた元が S5 なら `#memory/<id>?from=connections`（思い出された側は `&recall=<recall id>` で 4.2 の形。上下は末尾の追記のとおり起きた日の順で、思い出された側が上に来ることもある）、S3 の戻るは「‹ つながり」、ナビの現在地は「つながり」
- 絵は、2 枚の紙片を一本の糸で結んだ形（画面の「ふたつの日」と同じ）。既存の 2 つと同じ 20px・線 1.75。選択中は 2 枚の紙片を `fill-card` で白く抜く
- 帯の作りは変えない（`pt-1` + 項目 58px + `max(env(safe-area-inset-bottom), 6px)`。第8節 #23）。3 等分で、402pt で 1 つ約 123px、375pt で約 114px。文字は `whitespace-nowrap` で折り返さない。3 つの画面のどれでも帯の高さが 68px（ブラウザ）で同じことを撮って確かめた
- S5 は S1 / S2 と同じく `KeepAlive` で残し、位置を覚えて戻す

### API の形（`GET /api/connections`。architecture 5.14）

- `{ items, beads }`。`items` は一組 = 一本の糸 = 一枚（見本の `{ nodes, edges }` は、組の一覧を描くには遠回りなのでやめた）。`memory` が書いたひとこと（新しい側）、`related_memory` が思い出した昔のひとこと
- **`not_related`（関係ないかも）は返さない**。原則 1「AI の推測を事実として確定しない」と原則 2「関係なければ提案しない」から、利用者が関係ないと返した結び目を、結ばれたものとして並べ続けない。札そのものは消さず、S3 では今までどおり退いた札として残り、そこで「関係ないかも」を外せばこの画面に戻る
- 組は新しい 50（P0 ではページ送りなし。続きは P2）、帯の粒は起きた日がわかる記憶 500 まで。札の両端を `memories.user_id` で絞る（X-11）。D1 は `db.batch` で 1 往復。マイグレーションは要らない
- 反応は今ある `PATCH /api/recalls/:id` をそのまま使う（新しい API は作らない）

### 糸の帯の振る舞い（土台の作業で決めたこと。`web/src/connections/loom.ts` の `layoutLoom`）

- x = 10 + (t − t0) / (t1 − t0) × (幅 − 20)。t は day ならその日、month は 15 日、year は 7 月 1 日。`unknown` は置かない（「いつだったか」を含む組は一覧には出し、帯には置かない）
- **t0 を組の両端の年まで広げる**: 粒は新しい 500 件で切れるので、粒より古い組の端が帯の外に出ないよう、一番古い年は粒と組の両端から取る
- **t1 を先の日付まで伸ばす**: t1 は今年の翌年の 1 月 1 日。起きた日に先の日付（validate は 2100 年まで受け付ける）があれば、端に積まないようその年の翌年まで伸ばす
- 年の縁の境目は 6px あける。ただし 1 年の幅の 1/3 まで（ずっと昔の記憶があっても縁が潰れない）
- **年の文字の間引きと位置の制限**: 文字が 44px より近づくときは、一番新しい年から数えて間引く。文字の中心は帯の端から 16px の内側に収める（「2024」が帯からはみ出さない）
- **今年だけのときは月の文字**: 年の代わりに 1月・4月・7月・10月を、その月の真ん中に出す（同じ位置の制限）
- 弧の高さは 8 + 30√(span / 帯の幅)。短い糸から順に決め、端を 6px 以内で分け合う糸は先に置いた糸より 6px 高くして入れ子にする（最大 54）
- 実装で足したこと: 帯の幅は実際の幅を測って `viewBox` に渡す（`ResizeObserver`）。362 の `viewBox` を縮めて描くと、375pt の端末で年の文字が 13px 弱になるため。測れないときは 362

### 反応とシート

- 一組のどこを押してもシートが開く（「ひらく ›」の `::after` を組いっぱいに）。シートは DateSheet と同じ div の作り（`role="dialog"`、`aria-modal`、`aria-labelledby` は見出しと隔たり）で、`body` の直下に出し（`Teleport`）、開いている間は後ろ（画面と下部ナビを包む `.safe-area`）に `inert` を付ける。開いたら見出しにフォーカス、閉じたら押した組へ返す。閉じ方は「とじる」・地を押す・Esc（11/7 のブラッシュアップで「下へなぞる」を足し、DateSheet・S3 の「消しますか」と同じ `useSheetDrag` に載せ替えた。末尾の 2 つめの追記）
- 「そうだった」「関係ないかも」は S3 の札と同じ。同じボタンをもう一度押すと `none` に戻す。失敗したら印を戻し、ボタンの下に「記録できませんでした」
- 「関係ないかも」にした組は、シートを閉じたときに薄れて上へ抜け（280ms）、一覧と帯から外れる。フォーカスは次の組へ、無ければ h1 へ。最後の 1 組なら空の画面になる
- 実装で足したこと: 閉じて外した後に記録が失敗したら、組を元の印で一覧に戻す。画面を離れたとき（シートの「ひらく ›」で S3 へ、戻るボタン）はシートを動かさずに閉じ、`inert` を外す。S3 で消した記憶の組は取り直しを待たずに外す。取り直しは記録中の組の印を古い値に戻さない

### 動き

（11/7 のブラッシュアップで値と作りを変えた。いまの値は末尾の 2 つめの追記と wireframes 9.7。下はこの ADR を書いたときの値）

- 最初に読み込んだときだけ、組が 90ms ずつずれて 600ms で現れ（5 組目まで）、本縫いの糸は 900ms、帯の弧は 1100ms で描かれる。S3 から戻ったときは裏で取り直して入れ替えるだけで動かさない（KeepAlive で外れた要素を戻すと CSS の動きが最初からやり直されるので、入ってくる動きの class は 2.4 秒で外し、離れるときにも外す）
- シートは地を 200ms で暗くし、340ms で下から上がる。糸は 220ms 遅れて 760ms で描き、結び目は 360ms でとまる。「そうだった」で 640ms かけて本縫いに描き直す
- `prefers-reduced-motion: reduce` では動きも遷移もすべて止めて、状態だけを切り替える（画面の側も待たずに閉じる・外す）

## まだのこと

- 50 組を超えた分の「もっと前を見る」は P2（帯は 11/7 のブラッシュアップで押せるようにした。末尾の 2 つめの追記）
- Android の戻るボタンはハッシュを戻すだけなので、シートを開いたまま押すとシートだけでなく画面ごと前に戻る（DateSheet と同じ問題。シートは閉じて `inert` も外れる）
- 実機で見ること（ヘッドレスの Chrome でしか見ていない）: WKWebView の `inert` と `Teleport` 先の固定配置・セーフエリア、`line-clamp` の中の `mark` の `box-decoration-break`、VoiceOver で `aria-labelledby` の 2 つ（見出しと隔たり）と `role="list"` の読み上げ、SVG の弧の立ち上がり（`scaleY`）と一針ずつの糸の動きの重さ（`stroke-dashoffset` は 11/7 にやめた）、極端に長い理由での結びの高さ（一覧は 3 行で切る。シートは全文でシートごとスクロールする）
- 一組の高さは、明朝の行送り（31px）で見本の 360〜420px より少し高い（402pt で約 465px）。最初の画面に見えるのは帯と 1 組と少し（見本は 1.5 組）
- 理由の文は Claude の出力しだい（見本の文は実際の札と足しから取った）

## 追記: 組の上下は起きた日の順（11/7、実機）

開発者が 2019 年の引っ越しを今日書き、2026 年 7 月の「冷蔵庫が壊れた」が思い出された。見本と最初の実装は「上 = 書いた方、下 = 思い出した方」だったので、上に 2019 年・下に 2026 年が来て「7年3か月あとの、あのとき」と出た。開発者の言葉は「なんかつながり逆になってない？」。

見本は「思い出した方はいつも昔の日」と考えていたが、昔のことを後から書くと逆になる。そこで次のように変えた（`web/src/connections/pair.ts` の `sidesOf`）。
- 上下は起きた日の順（上 = 後の日、下 = 前の日）。隔たりはいつも「〜まえの」か「おなじ〜の」になる
- どちらかが「いつだったか」か、同じ日・同じころなら、書いた方を上に置く
- 紙は位置で決める（上は便箋、下は一筆箋）。思い出した一文の印と、S3 を札の形（`?recall=`）で開くリンクは、上下ではなく思い出された側に付ける
- 添え書きを「書いたひとことと、そのとき浮かんだ昔のひとこと」から「そういえば、で結ばれたふたつの日」に変えた（思い出された方が昔とは限らないため）
- 組の並び（札の新しい順）と帯の弧（日付の位置で決まり、向きを持たない）は変えない

## 追記: ブラッシュアップ（11/7、ADR-0011）

開発者の「全体ブラッシュアップ / … / 動きをしっかりつけ / 単調にならないように / そして、つい記録したくなるようなものにして。」を受けて、3 回目の見直しの指摘（n=1, 2, 3, 4, 5, 7, 8, 11）を直し、動き・帯を押す・新しく結ばれた糸の出方を足した。
どの直しも、先にテストで再現してから直した（n=11 だけは headless Chrome の CDP のタッチで確かめた）。

### 一覧を読むことと反応の記録が重なったときの約束（見直し n=1, 2, 4。「反応とシート」に足す）

- 読み込み・取り直しを始めるたびに読み込みの番号（`version`）を進め、あとから始めた方の結果だけを使う
- **反応の記録を始めたときと終えたときにも番号を進める**。記録と時間が重なって読んだ結果は記録の前の値かもしれないので使わない。シートが開いている間に返った結果も使わない（開いている組が入れ替わらないように）
- 使わなかったら「取り直しの借り」（`owed`）を立て、**シートが閉じて、記録中のものも抜ける途中の組も無くなってから取り直す**（`catchUp`）。n=2 の番号を進める直しと n=4 の取り直しの直しを 1 つの約束にまとめた（n=4 の直しだけだと n=2 の場合がまた起きる）
- 記録に失敗したら、取り直しで一覧が入れ替わっていても、**いま画面にある組を id で探して**元の印に戻す（n=1。掴んでいた古い組を戻すと「✓ そうだった」と本縫いが残っていた）

### 記録の失敗の知らせ（見直し n=3, 8）

- シートが開いていて同じ組なら、シートの中のボタンの下（`role="status"` を初めから置いて文字だけ入れ替える。3 秒）
- シートが閉じていれば、組を元の印で一覧に戻し、組の足に「記録できませんでした」（`text-ink-soft` 14px。判があれば判と並べる）を出して、その組をもう一度ひらくまで残す（あとでスクロールして戻ってきても見えるように）。下がっていく途中のシート（PairSheet が closing を出してから閉じるまで）は閉じたものとして扱う。抜けていく途中の組をひらき直すと抜ける動きを取り消し、外すかどうかは次に閉じたときに決め直す（見直し 4 回目、11/7）。
  画面に常に置いた読み上げ用の知らせ（`sr-only`、`role="status"`）でも読む。触覚は `failed`。フォーカスは動かさない。ただし組が抜ける途中で失敗したら、すぐ戻した組の「ひらく」へ返す

### 引用の切り分けと印（見直し n=5, 7）

- 一覧で寄せる字数を 80 字から **56 字**にした（`PairCard.vue` の `LIMIT`）。前の文脈は 24 字までで、「…」+ 前 + 引用 が 56 字に収まるまで縮める（`excerpt.ts`。後ろは行で切れてよい）。
  56 は、いちばん狭い 375pt の一筆箋で 4 行に入る字数（16 字 × 4 = 64）から禁則の余裕を引いた数。80 字以下の本文は切り出されず、`line-clamp-4` で印が丸ごと隠れていた
- 印は色の地だけに頼らない: `mark.quote-mark` に朱の点線の下線（1.5px、2px の点と 2.5px のすきま）を足し、`mark` の前後（外）に読み上げ用の「」（`sr-only`）を置いた。シートも同じ

### シート（見直し n=11）

- motion の `useSheetDrag`（`.sheet-paper` / `.sheet-backdrop` / `.sheet-grip`）に載せ替え、自分で書きかけた `connections/sheetDrag.ts` は消した。
  紙は 460ms・`ease-spring` で上がり、地は 280ms でふわっと暗くなる。閉じ方は「とじる」・地を押す・Esc・下へなぞるの 4 つで、どれも 280ms・`ease-out-soft` で下がってから閉じる。
  なぞって閉じる境目は、下げた量が `min(高さ × 0.3, 140px)` を越えたとき、または下へ 0.5px/ms 以上で 16px 以上払ったとき
- **開いている間は後ろの一覧がスクロールしない**。中身がスクロールするこのシートでは、中身（`data-sheet-scroll`）だけが動く
- motion の CSS の `.sheet-paper::after`（ばねで行きすぎたときに下の縁が浮かないよう紙を 64px 伸ばす）は、中身がスクロールするこのシートではスクロールの範囲を伸ばすので、`.pair-panel` では消した。代わりに地の色の影（`0 64px 0` の `paper`）で隙間を埋める

### 動き（「動き」の節を置き換える。値は wireframes 9.7）

- **動かすのは `transform` と `opacity` だけ**。帯の弧を「描く」のに `stroke-dashoffset` は使わず、縁から立ち上がる動き（`scaleY` 0.12 → 1、`ease-spring`）にした。糸は 8 針の区間を `opacity` で順に現して「一針ずつ縫う」に見せる。古い `thread-draw` などは使わなくなった
- 最初の表示: 組は 70ms ずつずれて（6 組目まで）下から 14px・460ms で現れ、本縫いは 8 針を 45ms ずつ、帯の弧は古い端から 120ms + 70ms ずつ（11 本目まで）。すべて終わるまで 1.9 秒（`WEAVE_MS`。そのあと class を外す）
- 「そうだった」はしつけ糸の上を一針ずつ縫い直し、下の結び目が留まって、ボタンが判のように弾む。外した組は薄れて抜け、下の組が FLIP で詰まる。組は押すと沈む（`.press`）
- 触覚: 「そうだった」→ `stamp`、「関係ないかも」・取り消し → `tap`、失敗 → `failed`、帯を押す → `select`

### 帯を押す（「まだのこと」の「帯は押せない」を閉じる）

- 押した位置から 22pt 以内でいちばん近い弧の組へ一覧が動き、組と弧が 1.4 秒ほのかに光る（`loom.ts` の `pickArc`）。同じ近さなら短い弧（小さくて押しにくい方）を選ぶ。何も無い所を押しても何もしない
- 押せるのは指だけで、図は `aria-hidden` のまま（読み上げとキーボードは一覧から同じ組へ行ける）

### 単調にしない（「N 本の糸」と押し葉は入れない）

- 押し葉は置かない。帯は情報の図なので、飾りが並ぶと読みにくくなる。押し葉と封蝋は season が季節で替えている（シートの封蝋はもう季節で変わる）
- 「N 本の糸」も出さない。API は組を新しい 50 までしか返さないので、それを超えると数が嘘になる（総数には Worker の変更が要る）
- 代わりに、**前に見たときより後に結ばれた組だけが、戻ったときに現れて糸が渡される**。自分が書くと糸が増える、が目で見えるので「つい記録したくなる」に効く

### テストの書き換え（弱めていない）

- 「地を押しても閉じる」は `.sheet-backdrop` を押す（`useSheetDrag` の形）
- 「戻ったとき」は、`role="status"` が無いことではなく「よみこみ中」の文字が無いことを確かめる（読み上げ用の知らせを常に置くようにしたため）

## 追記: 帯を横に送れる年表にする（11/8、実機）

年が増えると、見える幅に詰めた帯は 1 年が狭くなり、弧も年の文字も読めなくなる。そこで次のように変えた（`web/src/connections/loom.ts` の `layoutLoom({ scroll: true })`、`ThreadLoom.vue`、`connections.css` の `.loom` / `.loom-frame`）。
- 見える幅に詰めると 1 年が **150px** を割るときだけ、1 年 **180px** で並べて帯を横に送る（少しだけ送れる帯にはしない）。帯の幅は **3600px** まで（それより長い年月は 1 年を縮める）
- 入れ物は `figure.loom`（`overflow-x: auto`、`touch-action: pan-x pan-y`、スクロールバーは出さない）。外枠は `touch-pan-y` のままで、横のなぞりは帯の中だけが受ける（S3 の左端からなぞって戻る決まりは崩さない）
- 開いたときは**右端（新しい側）**から。位置は右端からの量で覚え、年が増えても、KeepAlive で外れて戻っても同じ所を見せる
- 戻ったときに新しく結ばれた組があれば、そのうち一番新しい端の弧が見える所まで送る。一覧で組をひらいたときも、その組の弧が見える所まで送る（入るなら弧を真ん中に、入らなければ新しい端を右のぼかしの内側 28px に。もう見えていれば動かさない。動きを減らす設定では飛ぶ）
- 押した位置は figure の左端からの量に送った量を足して帯の座標にする。送っている途中や送った直後（scroll の知らせから **120ms** 以内）に触れた指、押している間に 3px より送れた指は、弧を押したことにしない
- 左右の端の 24px の薄いぼかし（`paper` から透明へ）は、その向きに続きがあるときだけ出す（`data-more-start` / `data-more-end`。`opacity` だけ、動きを減らす設定では遷移しない）
- 帯は `aria-hidden` のまま（読み上げの本体は一覧）
